# מבט־על LIVE — multi-ai

אתר RTL בעברית לריכוז מקורות צפייה והאזנה: חדשות, טלוויזיה, רדיו, ספורט וסרטים.

## הפעלה
זהו אתר סטטי. פתחו את `index.html` בדפדפן, או הפעילו GitHub Pages:
1. Repository → Settings → Pages.
2. תחת Build and deployment בחרו Deploy from a branch.
3. בחרו `main` ו-`/(root)`, ואז Save.

## מה עובד בגרסה זו
- ממשק רספונסיבי בעברית.
- חיפוש וסינון לפי קטגוריות.
- נגן YouTube וקובצי מדיה ישירים נתמכים.
- קישורים למקורות רשמיים; מקורות אישיים נשמרים ב-localStorage בדפדפן.
- אין צורך במפתח API או שרת.

## מגבלות חשובות
- זו אינה מערכת AI מחוברת למודל. "עוזר המדיה" מסנן את הקטלוג המקומי בלבד.
- לא כל אתר מאפשר הטמעה. חלק מהמקורות ייפתחו רק באתר המקור.
- לא סופקו כתובות stream מאומתות לכל הערוצים; אין הבטחה שכל ערוץ ינגן מתוך האתר.
- אין פרוקסי בגרסה זו. אין לעקוף DRM, הרשאות, חסימות או תנאי שימוש. אין אפשרות להבטיח אישור נטפרי: יש לבקש מנטפרי אישור לכל דומיין/מקור, ולוודא שהפרוקסי עצמו מאושר לפני שימוש.
- המאגר כרגע פרטי. כדי שהאתר יהיה נגיש לכל אחד, יש לשנות אותו ל-Public (Settings → General → Danger Zone → Change visibility) ולהפעיל GitHub Pages. שינוי הנראות לא בוצע על ידי הקוד הזה.

## פרטיות
אין אנליטיקה ואין שליחת נתונים לשרת. מקורות מותאמים אישית נשמרים מקומית בדפדפן.
