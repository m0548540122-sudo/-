# מבט־על LIVE · multi-ai

אתר מדיה בעברית (RTL) בעיצוב כהה ואנימציות, לריכוז מקורות חדשות, טלוויזיה, רדיו, ספורט וסרטים.

## הפעלה
פתחו את `index.html` בדפדפן. האתר סטטי ואינו דורש שרת, התקנה או מפתח API.

## פרסום ציבורי דרך GitHub Pages
המאגר הנוכחי עדיין מוגדר Private. כדי שכל אחד יוכל לפתוח את האתר:
1. ב-GitHub פתחו Settings → General → Danger Zone → Change repository visibility → Public.
2. פתחו Settings → Pages.
3. תחת Build and deployment בחרו Deploy from a branch.
4. בחרו branch בשם `main` ותיקייה `/(root)`, ואז Save.
5. אחרי שהפריסה מסתיימת, כתובת האתר תהיה בדרך כלל: https://m0548540122-sudo.github.io/multi-ai/

## יכולות בגרסה 2.0.0
- עיצוב פרימיום כהה, גרדיאנטים, אורביט, חלקיקים ואנימציות CSS.
- התאמה למחשב, טאבלט ונייד; תמיכה בהעדפת Reduce Motion.
- חיפוש וסינון לפי חדשות, טלוויזיה, רדיו, ספורט וסרטים.
- נגן YouTube וקובצי MP4/MP3 ישירים.
- קישורים למקורות רשמיים.
- הוספת מקורות אישיים ושמירתם ב-localStorage בדפדפן.
- אין אנליטיקה ואין שליחת חיפושים או מקורות אישיים לשרת.

## מגבלות ושקיפות
- אין חיבור למודל AI חיצוני בגרסה הזו. Media Intelligence הוא חיפוש/סינון מקומי, לא צ'אט AI.
- לא כל גוף שידור מאפשר הטמעה באתר חיצוני. חלק מהמקורות נפתחים באתר הרשמי.
- הקטלוג מכיל קישורים לאתרים רשמיים; לא סופקו ולא אומתו כתובות stream ישירות לכל ערוץ.
- אין פרוקסי בגרסה הזו. אין לעקוף DRM, הרשאות או תנאי שימוש.
- לא ניתן להבטיח שהאתר או מקור מסוים יעבדו בנטפרי. יש לקבל אישור נטפרי לכל דומיין, מקור ופרוקסי בנפרד.
- GitHub Pages וחשיפת המאגר לציבור לא הופעלו אוטומטית; נדרשת פעולת בעל המאגר לפי ההוראות למעלה.
